# Code of Conduct — maatify/php-category

[![Maatify Category](https://img.shields.io/badge/Maatify-Category-blue?style=for-the-badge)](https://github.com/Maatify/php-category)
[![Maatify Ecosystem](https://img.shields.io/badge/Maatify-Ecosystem-9C27B0?style=for-the-badge)](https://github.com/Maatify)

## Our Standard

Contributors are expected to communicate respectfully, focus on evidence and
maintainable engineering, and keep discussions relevant to the package's
framework-neutral Category scope.

## Enforcement

Project maintainers may clarify, remove, or reject contributions that violate
this standard. Report concerns privately through the repository maintainers.
